CI/CD

Cada cambio en main se construye, se prueba y puede llegar a un entorno sin un ritual heroico.

Montar el servidorIntegraciónHerramientas de pipeline
0% completado

CI/CD introduce automatización y monitoreo continuo desde la integración hasta el despliegue. Es la respuesta al miedo de juntar código el viernes.

Conferencia

El tubo

Continuous Integration: cada commit (o PR) dispara una construcción y pruebas. Continuous Delivery: el artefacto queda listo para producción. Continuous Deployment: además, se publica solo si el tubo está verde.

Un pipeline típico: obtener código → construir → analizar → probar → empaquetar → desplegar → verificar. Jenkins, GitHub Actions, GitLab CI, Circle, Azure DevOps: distinto YAML, misma idea.

Lo que debes montar

  • Un servidor o servicio de CI.
  • Integración: el push dispara el tubo.
  • Herramientas de build y empaquetado.
name: ci
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: python -m compileall .
El tubo es productoSi el pipeline es flaky, el equipo deja de creerlo. Un test inestable es un incidente cultural.

Cortos

Un concepto por tarjeta. Léelos en voz alta si puedes.

Artefacto

El binario, imagen o paquete que desplegarás. No redespliegues 'lo que había en la laptop'.

Gates

No despliegues si fallan tests, linters o el escaneo de secretos.

Ambientes

dev → staging → prod. Promueve el mismo artefacto; no reconstruyas en prod.

Secrets del CI

El CI es un tesoro: tiene llaves de nube. Mínimo privilegio, rotación, logs sin secretos.

Recorrido

Como el walkthrough de CS50: solo para arrancar, no para sustituir el problem set.

  1. Elige GitHub Actions o GitLab CI (gratis y suficiente).
  2. Pipeline que corre en cada push: lint o tests mínimos.
  3. Guarda un artefacto (un .tar o una imagen en un registry de laboratorio).
  4. Añade un job de deploy a un entorno falso (una rama gh-pages o un directorio).

Problem set

Rúbrica: correctitud — El tubo corre en un clone limpio, no en tu laptop. · diseño — Jobs cortos, cacheados con sentido, secretos en el almacén del CI. · estilo — YAML legible; nombres de jobs que un extraño entiende.

Recuerdo activo

Cierra las notas. Elige. El error también enseña.
