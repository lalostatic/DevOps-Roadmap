Conferencia

El sistema operativo como puente

Un sistema operativo media entre tú y el hardware: procesos, memoria, disco, red. En este oficio ese puente casi siempre se llama Linux. Ubuntu es un buen primer destino porque documenta mucho y perdona más.

POSIX es el contrato de cómo se comportan shells, archivos y procesos en sistemas tipo Unix. Por eso un script bien escrito corre en Ubuntu, Debian y, con matices, en macOS.

El sistema de archivos no es una carpeta bonita

En Linux todo es un archivo: discos, sockets, pipes. /etc guarda configuración. /var logs y estado. /home a las personas. /proc y /sys son ventanas al kernel. Aprende a leer rutas antes de instalar el siguiente panel.

pwd; ls -la
cd /var/log && less syslog
ps aux | head
ss -tulpn
chmod 640 secret.env
sudo systemctl status ssh

Scripting

Bash (o PowerShell en Windows) convierte una receta en un programa. Python y Go también sirven y a menudo escalan mejor. Empieza por Bash para la gramática del sistema; pasa a Python cuando el script crezca.

PrácticaNo memorices 200 comandos. Memoriza navegación, permisos, procesos, red básica, y cómo pedir ayuda: man, --help, tldr.

Cortos

Un concepto por tarjeta. Léelos en voz alta si puedes.

Shell

Un intérprete que lee tu texto y habla con el kernel. Bash es el más común en servidores.

Permisos

rwx para usuario, grupo y otros. 644 y 755 no son magia: son bits.

Procesos

PID, señales, systemd. Si no sabes matar un proceso, no sabes operar.

Virtualización

Una máquina virtual simula hardware. Un contenedor comparte el kernel. No son lo mismo.

Recorrido

Como el walkthrough de CS50: solo para arrancar, no para sustituir el problem set.

  1. Instala Ubuntu en una VM (VirtualBox, UTM o cloud gratuito) o usa WSL2.
  2. Crea un usuario, una carpeta en /opt y un script que haga backup de un directorio.
  3. Usa chmod, ps, grep y journalctl una vez cada uno, con propósito.
  4. Escribe un Bash de 20 líneas con set -euo pipefail.

Problem set

Rúbrica: correctitud — El script corre en una VM limpia sin pasos secretos. · diseño — Permisos mínimos; no todo es 777. · estilo — El Bash tiene set -euo pipefail y nombres claros.
